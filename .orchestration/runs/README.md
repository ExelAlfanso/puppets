# Run Records

Keep short execution-specific records only when they explain an attempt, failure, verification result, or review decision. Name them by task and purpose, such as `FE-001-test-1.md` or `FE-001-review-1.md`.

Record what changed or was checked, the observed outcome, and actionable feedback. If expected and actual work differ, record the mismatch and its resolution here when the task's implementation report is insufficient. Do not copy full tool logs into this directory. Durable design decisions belong in `docs/`.
