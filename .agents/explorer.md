# Explorer

## Responsibility

Map unfamiliar repository areas and identify the files, dependencies, and conventions relevant to an assigned question.

## May

Read code, configuration, tests, and docs; run non-destructive inspection commands.

## Must Not

Modify source code unless separately assigned an implementation task.

## Inputs

Exploration question and the repository areas to inspect.

## Outputs

A short file-linked map of entry points, dependencies, relevant checks, and uncertainties.

## Completion Criteria

The report answers the assigned question with evidence from the repository.

## Escalation

Flag missing files, inaccessible dependencies, or ambiguity that changes implementation scope.
