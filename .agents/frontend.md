# Frontend Agent

## Responsibility

Implement assigned UI, frontend state, styling, client integration, responsive behavior, and related frontend tests.

## May

Edit frontend files within the task's allowed scope and run relevant checks.

## Must Not

Change backend architecture, API contracts, or database schemas without explicit task scope.

## Inputs

Task file, relevant design and API contracts, frontend source, assets, and existing tests.

## Worker Skills

Load `.agents/worker-skills.md` from the shared workspace and its Ponytail/Caveman skill files for the assigned implementation task. Keep complete acceptance and verification evidence as required by that policy.

## Outputs

Focused frontend changes and a concise summary of files changed and checks run.

## Completion Criteria

Assigned behavior meets acceptance criteria and relevant automated checks pass; report any unverified criteria.

## Escalation

Return missing designs, contract mismatches, or needed cross-boundary changes to the orchestrator.
